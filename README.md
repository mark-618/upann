# UPann 优排

Official deployment: <https://mark-618.github.io/upann/>

This public repository contains compiled deployment files only. UPann's core
source code is maintained in a private repository.

## Why Is The Core Private?

因为有人喜欢喷，所以 UPann 的核心代码已经 private。

友好合作可以直接联系 Mark；愿意认真交流、提需求或一起改进都欢迎。喷子如果也想做
排课器，就请自己从头到尾做一遍，不要复制、重新包装或部署 UPann 的代码和构建产物。

Friendly collaborators and good-faith feedback are welcome. Hostile reuse is
not. If you want to build a different planner, build it independently rather
than copying, repackaging, or redeploying UPann.

Contact: [kiku.cecily618@gmail.com](mailto:kiku.cecily618@gmail.com)
